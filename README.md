# Dialogue Options

Customize the size and opacity of the dialogue box and dialogue choices.

## Settings

### Dialogue Box
- Scale: 25%–150%
- Opacity: 0%–100%

### Dialogue Choices
- Scale: 25%–150%
- Opacity: 0%–100%

## Build

This repository uses the Dusklight mod SDK and GitHub Actions to build the native mod for every supported platform and combine the platform libraries into a single `.dusk` bundle.

Artwork is stored in `res/icon.png` and `res/banner.png` and referenced by `mod.json`.
